# Libraries in board\lib, as circup module names. A maintainer job: students
# never run circup, and tools\setup.ps1 does not either -- board\lib is
# committed, so a fresh clone already has exactly these.
#
# To add or update one, install into the repo (not onto the board), as plain
# .py so the source stays readable:
#
#   .\.venv\Scripts\circup.exe --path .\board --board-id seeeduino_xiao_rp2350 `
#       --cpy-version 10.3.1 install --py -r device-requirements.txt
#
# THEN DELETE board\lib\adafruit_bus_device. circup installs it as a
# dependency, but it is built into this board's firmware, and a copy in lib\ is
# loaded instead of the built-in one. Then full-sync with tools\sync.ps1.
